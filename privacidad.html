Política de privacidad

Última actualización: 11 de noviembre de 2026

Finanzas es una aplicación de escritorio de uso personal que se ejecuta únicamente en la computadora de su usuario. Esta política explica qué datos de Google usa y qué hace con ellos.

Datos a los que accede

Con la autorización del usuario, la aplicación usa el permiso gmail.readonly de la API de Gmail para:

  • buscar los correos de notificaciones del banco y de Yape, de los remitentes configurados en la aplicación;
  • leer el contenido de esos correos y descargar sus adjuntos (estados de cuenta e historial de Yape).

La aplicación no envía, modifica ni elimina correos, y no lee correos de otros remitentes.

Cómo se usan

Los datos se usan solo para registrar los movimientos (fecha, monto, comercio y cuenta) y conciliarlos con los estados de cuenta, de modo que el usuario vea sus gastos, ingresos y presupuesto.

Dónde se guardan

  • Los movimientos se guardan en una base de datos SQL Server instalada en la misma computadora del usuario.
  • El token de acceso de Google y las contraseñas se guardan en el Administrador de credenciales de Windows.
  • No hay servidores propios: ningún dato sale de la computadora del usuario, salvo las consultas a la API de Gmail.

Con quién se comparten

Con nadie. Los datos no se venden, no se transfieren a terceros, no se usan para publicidad ni para entrenar modelos de inteligencia artificial.

El uso de la información recibida de las API de Google cumple la Política de datos del usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso y borrar los datos

  • El acceso a Gmail se puede revocar en cualquier momento desde myaccount.google.com/permissions.
  • Los datos locales se borran eliminando la base de datos de SQL Server y desinstalando la aplicación.
